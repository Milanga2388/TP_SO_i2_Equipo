d- No necesariamente. Al actualizar un fork, tus cambios locales o propios no se pierden automáticamente. Git buscara combinar los cambios del repositorio actualizado con los tuyos. Si se encuntran modificaciones en las mismas partes de los archivos, pueden aparecer conflictos de fusión (merge conflicts) que deberás resolver manualmente. Solo se perderían cambios si los sobrescribes o eliminas explícitamente.

  1. git clone https://github.com/Milanga2388/TP_SO_i2_Equipo.git (direccion del repo)
  2. cd [nombre de la carpeta donde estan los archivos del repositorio]
  2. git checkout -b [nombre del fork]-> para hacer un fork
  3. git add . -> luego de realizar los cambios
  4. git commit -m "comentario" -> en el comentario se describen los cambios realizados
  5. git push -> si estas en el original
  6. git push --set-upstream origin [fork] -> si estas en un fork
